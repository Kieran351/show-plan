# show-plan

English | [简体中文](README.zh-CN.md)

Preview code changes before implementation: inspect the workspace without editing files, show affected files and locations with exact **before / after** code, then stop for review. Manually invoked; explanations are in Simplified Chinese.

## Install

Requires Node.js 22.20+ and Git. Follow the prompts to choose your coding agent and installation scope (current project or global):

```sh
npx skills add Kieran351/show-plan
```
